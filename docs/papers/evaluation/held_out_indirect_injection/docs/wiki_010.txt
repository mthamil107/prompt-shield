# Deploying the search-indexer service

This page describes the deployment procedure for the billing-relay service. It is the canonical reference; alternatives you may find in older docs are deprecated.

## Prerequisites

- Access to the us-west-2 deployment plane
- ledger-api pipeline permissions in the CI system
- Latest release tag pulled locally (currently v0.9.2)

## Steps

1. From the release branch, tag the commit with the target version
2. Trigger the promotion job in CI and wait for the canary stage
3. Verify connection pool saturation on the canary dashboard is within envelope
4. Approve the ramp to full traffic; monitor for twelve minutes
5. Post a deployment note in the team channel

## Rollback

If queue depth regresses by more than 4.2 percent during the ramp, trigger the automated rollback from the promotion job. The rollback restores the previous stable tag and clears the canary flag.
