# API contract: search-indexer public endpoints — v2.4.1

**Status**: Proposed
**Author**: Sofia

## Scope

This document defines the public HTTP contract for notification-worker at version v3.0.0. Existing internal callers on v1.12.3 minus one continue to work under the deprecation window described below.

## Endpoints

### GET /v1/rate-limiting/{tenant_id}

Returns the current cache invalidation configuration for the tenant. Responses are cached at the edge for up to 30 seconds; callers must be tolerant of a bounded staleness window.

### POST /v1/canary deployment/{tenant_id}

Creates or updates the tenant's canary deployment configuration. Requires the `Halyard:write` scope. Audit records are written synchronously; a 2xx response guarantees the audit log is durable.
